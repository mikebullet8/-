# Proyecto: negocio de creador con IA

Habla siempre en español con el usuario, de forma directa y práctica.

## Objetivo
Construir y hacer crecer canales de contenido (YouTube, TikTok, Reels) y productos digitales,
y desarrollar los proyectos de software que vengan de Codex.

## Skills disponibles (.claude/skills)
| Skill | Para qué |
|---|---|
| `plan-canal` | Plan completo del canal, de cero a rentable, semana a semana |
| `nicho-rentable` | Nicho, identidad, espectador ideal y 100 ideas de vídeo |
| `guiones-virales` | Títulos, miniaturas, ganchos y guiones completos |
| `algoritmo-youtube` | Cómo crece un canal y estrategia de testeo |
| `produccion-ia` | Flujo de producción con IA y checklists |
| `monetizacion` | Fuentes de ingresos y cuándo activar cada una |
| `analitica-canal` | Revisión semanal y mensual de estadísticas |
| `responder-comentarios` | Respuestas y extracción de ideas desde comentarios |
| `producto-digital` | Producto en 24 h, página de ventas y embudo de emails |

## Reglas
- Honestidad: no inventar datos, testimonios ni cifras de ingresos; marcar estimaciones como estimaciones.
- Cuando falte contexto clave (nicho, recursos, metas), preguntar antes de entregar el plan.
- Entregables largos (planes, guiones, páginas de ventas) se guardan como archivos en `entregables/`.

## Proyectos de Codex
Los proyectos traídos desde Codex van en `proyectos/<nombre>/`, cada uno con su README.
Antes de modificar uno, leer su README y su código y ejecutar sus tests si existen.
